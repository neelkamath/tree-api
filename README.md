# Tree API

An API to update and read a tree data structure.

# Installation

1. Install [Node.js 20](https://nodejs.org/en/download).
2. Clone the repo using one of the following methods:

    - SSH:

        ```shell
        git clone git@github.com:neelkamath/tree-api.git
        ```

    - HTTPS:

        ```shell
        git clone https://github.com/neelkamath/tree-api.git
        ```

3. Change the directory:

    ```shell
    cd tree-api
    ```

4. Install the dependencies:

    ```shell
    npm i
    ```
   
## Usage

- To run the API server:

    ```shell
    npm start
    ```

- To run the automated tests:

    ```shell
    npm t
    ```
